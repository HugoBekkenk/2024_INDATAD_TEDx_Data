# TEDx Data Analysis

I created a data pipeline that collects daily YouTube data from TEDx videos for analysis.  
The pipeline is built using **Python** and **GitLab CI/CD**, with a **Google Data Studio** dashboard to visualize the insights.

The project also includes **AI-based clustering and sentiment analysis**, both implemented in a **Jupyter Notebook**.
